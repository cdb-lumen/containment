## Authored deliverables and appearance

Produce in this order: chamber with its carrier fit fixture, complete four-row fit, distribution pair, monitoring pair, then flush finish kit. Finish and review each family before adding the next; do not polish the whole room in one unreviewable batch.

Create new sources under `tools/assets/passenger-vault/`: `build.py`, `README.md`, `references.md`, `manifest.json` and `passenger-vault.blend`. The manifest defines every placement, bounds, mesh/material counts and hashes. Record Blender version, fixed procedural seed and reference URLs with the construction decisions they informed. Use real medical enclosure, gasket, pump cabinet and service-panel references; reference photographs are not texture licenses.

Export seven GLBs under `public/assets/passenger-vault/`: `chamber.glb`, `row-carrier.glb`, `distribution-north.glb`, `distribution-south.glb`, `monitor-north.glb`, `monitor-south.glb`, `service-finish.glb`, plus `CREDITS.md`. The builder must recreate the blend scene, original texture maps and all exports in a clean directory using `blender --background --python tools/assets/passenger-vault/build.py`. Document any installed dependencies and output-root option. Require repeatable geometry, placement and decoded texture hashes; record binary hashes too, explaining any exporter metadata variance. A manually edited GLB without reproducible source fails.

Use metre-scale assets, deck-centred local origins for repeated units and a room-origin flush kit. Bake Blender-to-glTF axis conversion once; apply scale and disallow negative-scale mirroring. Keep chamber/carrier resources shared across repetitions. Model pressure-shell curvature, lid seams, service access and supports before surface detail.

Use clean off-white coated shells, darker rough insulated carriers, exposed metal only at functional fittings, dark matte elastomer gaskets and restrained cyan live-state graphics. Pair the working-face cue with an upward-readable repeated vital/status symbol on each lid shoulder so southern occupancy does not depend on a hidden face. Colour alone or tiny text cannot establish living occupancy. No exposed figure is needed.

Wear follows use: slight wipe variation on shells, hand wear at access latches, tool marks at service fasteners and shoe scuffs on deck approaches. No blanket rust, blood, broken seals, failed displays or heavy frost implying abandonment. Approve silhouette, PBR separation and causal wear separately under matched camera/light; prettier lighting cannot earn a material pass.

## Ownership and stop rules

The asset author owns reproducible sources and exports; the single runtime writer owns attachment, loading lifecycle and game invariants; independent reviewers own verdicts. Isolated authors/reviewers may work in parallel, but only one heavy browser/render job runs at a time. No runtime or GPU work belongs to this planning assignment.

Before production, the rollout owner checks base drift, existing work and recorded reset synchronization for issue22, draft PR58 and the shared vault without discarding historical work. Routine silhouette, palette, file packaging and budget choices need no extra user approval. Changed passenger state/count, layout reservations, camera/HUD behavior, wave composition, progression or material style departures require escalation and renewed affected gates. After two runs without a new accepted gate or material evidence, change approach once; if that bounded recovery fails, save diagnostics, alert and pause rather than producing more plans or cosmetic captures.
