# Passenger Vault asset credits

Original procedural geometry and diagnostic grayscale materials authored by Hermes Agent for the Containment project under Viktor's direction. Reproducible source is `tools/assets/passenger-vault/build.py`, with `geometry_checks.py` and the package README and references record.

`chamber.glb` and `row-carrier.glb` are generated from original procedural vertices and Blender primitives. No PR58 asset, downloaded model, photograph, logo, external texture or other third-party asset is included. No texture maps are delivered in this geometry-only slice. Blender's glTF exporter writes the files.

The source package's `references.md` cites Tekna, Parker, BeaconMedaes catalog text via MedicalExpo, Rittal and Blender documentation consulted during the construction correction. Those references are not redistributed and do not confer texture or model rights. The record does not claim the initial author consulted them before modeling.
